# Braille Alphabet Pattern Recognition Quiz

An interactive quiz for learning Grade 1 Braille using the 26-letter alphabet. Shows a 6-dot Braille cell pattern and asks you to identify the corresponding letter, or shows a letter and asks you to arrange the dots. A "Hardest Letters" drill mode focuses on the letters you miss most often.

## Features

- Braille → Letter mode: identify the letter from a dot pattern
- Letter → Braille mode: click dots to reproduce the correct Braille cell
- Hardest letters drill: focuses on your most-missed patterns
- Streak counter, accuracy percentage, and per-letter error tracking
- Progress persisted in localStorage across sessions
